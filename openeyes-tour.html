OpenEyes feature tour

OpenEyes is the open-source electronic patient record for eye care. Moorfields Eye Hospital started it, and the Apperta Foundation maintains it. These are the screenshots the project publishes for OpenEyes v3, grouped by where each feature fits in a clinic day. Click any screenshot to see it full size.

Event modules in the codebase

OpenEyes organises the record as patient → episode (per subspecialty) → event → element. Each event type is a module.

ModuleWhat it records
OphCiExaminationExamination: visual acuity, IOP, DR grading, phasing, visual fields and subspecialty elements
OphTrOperationnoteOperation notes with procedure templates and EyeDraw annotations
OphInBiometryBiometry and IOL calculations, which feed the cataract op note
OphDrPrescriptionPrescribing from local formularies and drug sets
OphCoCorrespondenceTemplated clinic letters and discharge summaries, exported as PDF
OphCoTherapyapplicationApplications for funded therapies, such as anti-VEGF
OphCoCviUK Certificate of Visual Impairment
GeneticsDNA sample tracking and genetic results
PatientTicketingQueues for virtual clinics and other review workflows
