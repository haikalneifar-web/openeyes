# OpenEyes review

A review of [OpenEyes](https://openeyes.apperta.org/), the open-source electronic patient record for ophthalmology maintained by the Apperta Foundation.

- **`openeyes-tour.html`**: a visual tour of the OpenEyes v3 features. Open it in a browser. Click a screenshot to see it full size; the arrow keys move between screenshots.
- **`ANALYSIS.md`**: the strengths, gaps and best-fit settings for OpenEyes.
- **`img/`**: the feature screenshots, from [openeyes.apperta.org/oedetail](https://openeyes.apperta.org/oedetail). © Apperta Foundation.

The OpenEyes source code is at [github.com/appertafoundation/openeyes](https://github.com/appertafoundation/openeyes) (AGPL v3.0).
